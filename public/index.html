Agent Loop Lab · Reason → Act → Observe → Decide

The loop is the agent.

Run a scripted task through an instrumented agent loop over a fake support-desk tool set. Watch the trace show what a prompt alone never gives you: harness retries, a context budget that compacts, guardrails that block writes in code, and a no-progress detector that kills a stuck loop.

Safe educational demo. The "model" is a deterministic rule-based reasoner — a stand-in that exists to show the engineering around it. Everything runs in your browser; nothing is sent anywhere.
